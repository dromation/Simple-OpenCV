# SimpleOpenCV community code of conduct

This project welcomes learners, researchers and contributors across languages and experience levels.

- Treat people with respect. Critique implementations and claims, not individuals.
- Explain mathematical and technical disagreements with reproducible evidence.
- Help newcomers ask questions and make mistakes without ridicule.
- Do not harass, threaten, discriminate against or publish private information about others.
- Do not share images, recordings or datasets without the right to do so.
- Mark machine translations and unverified claims honestly.

These expectations apply to project issues, pull requests, discussions and other project spaces. Maintainers may edit or remove harmful content, warn participants, restrict participation or ban repeated or severe violations. Actions should be proportionate and consider context.

Report a concern to a repository maintainer through an available private GitHub contact channel. If no private contact is available, ask a maintainer to arrange one without posting sensitive details in a public issue. Maintainers should handle reports discreetly and avoid retaliation. A maintainer involved in a report should not decide its outcome alone.
