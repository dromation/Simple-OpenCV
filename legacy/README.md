# Legacy Simple-OpenCV

`original-main/` preserves the original Dromation repository at commit
`c94281ee8d5468712b2e8e9ec63f04dd885f9757` before the SimpleOpenCV visual studio was published.
Its original README, MIT notice, Kivy application, samples and DLL tools are
retained byte-for-byte. The `legacy` branch also preserves that exact commit.

These files are historical references, not the current application entry point.
They may require their original Python/OpenCV/Kivy environment. Their existing
notices and licensing boundaries remain unchanged.

`README-before-downloads.md` preserves the studio documentation immediately
before the desktop-download release. Use the [root README](../README.md) for the
current Windows, Linux, macOS and HTML editions.
